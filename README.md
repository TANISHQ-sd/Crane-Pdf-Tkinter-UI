# Crane Pdf Reader & Comparator (UI Prototype)

This project is a Tkinter-based desktop GUI application inspired by the Windows Notepad interface.
It serves as a UI foundation for a future PDF Reader and Comparator tool.

## Features
- Notepad-style top menu bar
- Scrollable File dropdown menu
- Custom application icon (Crane logo)
- Clean and professional UI
- Clickable menu options (logic to be implemented)
- Modular and readable code structure

## Tech Stack
- Python 3.x
- Tkinter (ttk)
